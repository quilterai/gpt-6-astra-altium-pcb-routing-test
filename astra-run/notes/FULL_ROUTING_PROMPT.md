# Full-board routing prompt

The [public routing prompt](../PROMPT.md) starts with the unchanged input
project and its SHA-256 manifest. It is an edited public version of the
historical instructions, with private destinations and dependencies on
unavailable setup/monitoring archives omitted.

The original full-board run started from preserved input, not the setup trial
or the final output. Historical notes describe that experiment; they are not
evidence that a new run is active.
